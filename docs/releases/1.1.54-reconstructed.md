# Immersive Engineer Decor&Controls&Tool Reforged 1.1.54-reconstructed

This corrective release supersedes `1.1.53-reconstructed` for distribution because that build could block normal traversal with incorrect collision geometry.

## Corrected

- `immersive_engineer_decor_controls_tool_reforged:iron_hatch`: the closed plate now occupies `Y=0..3`, matching the lower visual model instead of floating at `Y=14..16`; the open solid leaf rotates through all horizontal facings with the model's `2.875`-pixel depth.
- `immersive_engineer_decor_controls_tool_reforged:metal_sliding_door`: outline geometry now respects `FACING`, `HINGE`, `HALF`, and `OPEN`. Decorative lower and upper tracks remain selectable but no longer obstruct player movement when the door is open; the retracted solid stack still collides.

## Regression coverage

- All hatch horizontal facings, open/closed states, and powered values.
- All 32 sliding-door combinations of four facings, two hinges, two halves, and open/closed state.
- Exact model-component parity, valid bounds, non-full-cube checks, rotation-volume invariance, and solid-component probes.
- A world-space 33-position sweep of a real standing Minecraft player AABB (`0.6 x 1.8` blocks) through every open door orientation/hinge, with the closed door as a negative control.
