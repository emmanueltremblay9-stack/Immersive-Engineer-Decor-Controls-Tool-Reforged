# Immersive Engineer Decor&Controls&Tool Reforged 1.1.56-reconstructed

Published patch release. Changes below are relative to the published 1.1.55-reconstructed release; preparation began from main commit 8e8794624db0cf6ccc0be5397682b8c9ce6080f2. The immutable release/tag commit is `527b6d1afbcb283d6ff08cc40bc7a92ec229c399` and its qualified tree is `963b564f803f8537fa89033a5b055a7d8e2aa72c`. Current `main` includes later publication tooling and documentation; those maintenance commits do not identify the published JAR.

## Added

- Localization resources now cover 120 locales, compared with 12 in 1.1.55. Each locale contains the same 898 language keys and 223 manual source pages. The 12 additional keys expose existing behavior; they do not add gameplay features.
- Added a deterministic localization validator covering strict UTF-8, key and placeholder parity, manual coverage, autoload parity, and selected semantic expectations.

## Fixed

- Corrected tool descriptions and localized manual headings, including material-box usage, Japanese Muslee Bar naming, GUI index/subtitles, and Arabic manual-body wrapping that preserves words.
- Stimpack and sleeping-bag recipes accept all 16 wool carpet colors through minecraft:wool_carpets. A required GameTest checks both loaded recipes, their IDs, and one-item outputs for every color.

## Validation

Release qualification passed two clean builds without build cache, including the exact preparation commit 04258c36c4a7617118404759452f5b1208f9d782. Resource/metadata/sign validators, localization validation (120 locales, 898 keys and 223 manual pages per locale), 31/31 mocked publisher tests and all 189 required NeoForge GameTests passed. Both builds produced identical bytes; the release/tag commit retains the same qualified tree. After PR #31, the current publisher tooling separately passes 32/32 tests. See [the qualification and publication summary](../../release-evidence/1.1.56-reconstructed/SUMMARY.md).

## Known Limitations

- Resource parity and targeted linguistic review do not certify native fluency for all 120 locales. Native-speaker review remains unavailable.
- Earlier sampled client QA retained shared Hindi, Arabic, and Thai rendering limitations. Their exact upstream component attribution remains unverified. This release does not change production Java rendering or general tooltip geometry.
- Exhaustive runtime inspection of 120 locales and 223 pages per locale, arbitrary resolutions/UI scales, and per-frame artifact binding are not established.
- This version has no new client launch, Prism installation or packaged dedicated-server qualification; public artifact verification does not establish those runtime results.

## Compatibility

- Minecraft 1.21.1; Java 21.
- NeoForge minimum 21.1.230; release qualification uses 21.1.230.
- Immersive Engineering 1.21.1-12.4.2-194 is required.
- JEI 19.32.0.359 is optional. Additional dependency-version lanes from historical releases are not new 1.1.56 qualification.
- Engineer's Decor, Engineer's Tools, and Redstone Gauges and Switches are incorporated source projects. Attribution remains in CREDITS.md and NOTICE.md; they are not runtime dependencies to install.
