Vies d’accés
Passarel·les i suports
Els pilars d’acer, els pals tractats, els reixats, les passarel·les, les baranes, les escales de mà, les portes, les finestres i les trapes formen recorreguts compactes de servei per l’interior de les fàbriques.<br>
<br>
Les peces d’acer de les vies d’accés es fabriquen amb plaques d’acer. Elabora o col·loca una taula d’elaboració de metalls, insereix-hi un martell d’Immersive Engineering i martelleja lingots d’acer per obtenir plaques d’acer per a pilars, passarel·les, finestres, portes, baranes i altres decoracions d’acer.<br>
<br>
Col·loca-les on les màquines necessitin accessos de servei, passos elevats, pous de manteniment o vores més segures.
