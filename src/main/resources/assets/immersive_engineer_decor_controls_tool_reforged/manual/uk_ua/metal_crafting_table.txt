Верстак для обробки металу
Робоче місце для виготовлення пластин
<&recipe>Верстак для металу має комірку молота, повну сітку 3x3 і вихід.<br>
<br>
Для пластин IE покладіть молот інженера в комірку, матеріал — у сітку й заберіть пластину з виходу.<br>
<br>
Сталеві прикраси використовують сталеві пластини, сформовані тут.
