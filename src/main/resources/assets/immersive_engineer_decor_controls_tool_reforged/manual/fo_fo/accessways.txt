Atgongdarleiðir
Gonguleiðir og stuðlar
Stálstólpar, viðgjørdir viðarstólpar, ristir, gongubrýr, gelendarar, stigar, hurðar, vindeygu og lúkur skapa lítlar viðlíkahaldsleiðir inni í verksmiðjum.<br>
<br>
Stálpartar til atgongdarleiðir brúka stálplátur. Evna ella set eitt málmarbeiðsborð, set ein hamara frá Immersive Engineering í tað og hamra síðani stálstengur til stálplátur til stólpar, gongubrýr, vindeygu, hurðar, gelendarar og annað stálprýði.<br>
<br>
Set teir, har maskinum tørvar viðlíkahaldsatgongd, hækkaðar gonguleiðir, viðlíkahaldsskaktir ella tryggari kantar.
