Machine à traire
Équipement d'atelier
<&recipe>Orientez la machine vers des vaches adultes proches. Sans signal redstone, elle cherche à produire du lait toutes les 120 ticks. Un véritable seau vide dans l'entrée peut devenir un seau de lait dans la sortie ; sinon, le lait rejoint le réservoir de 4 000 mB s'il reste de la place. Prévoyez l'extraction des seaux remplis ou du lait liquide.<br>
Avec TerraFirmaCraft installé, l'adaptateur de ses vaches respecte les conditions natives de disponibilité, familiarité, sexe, âge et délai. Seul du lait ordinaire compatible pouvant être stocké est accepté ; tous les animaux ne deviennent pas pour autant trayables. Cette page décrit le comportement intégré, pas une interface expérimentale de remplacement.<br>
Les inventaires compatibles placés derrière ou dessous peuvent fournir les seaux vides et recevoir automatiquement les seaux de lait. L'entrée des seaux vides essaie d'abord l'arrière ; la sortie des seaux remplis essaie d'abord le dessous. La machine envoie aussi du lait liquide vers le bas. Ces transferts continuent quand la redstone suspend la production de lait.<br>
